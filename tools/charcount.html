사용법

  4. 새 글을 확인하려면 지우기 버튼으로 입력창을 비우고 다시 붙여넣으면 됩니다.

알아두면 좋은 정보

공백 포함? 공백 제외? 어느 쪽이 기준일까

결론부터 말하면, 대부분의 채용 시스템은 공백 포함 기준입니다. 잡코리아·사람인 같은 취업 포털과 대다수 기업 자체 채용 페이지는 띄어쓰기를 포함해 글자수를 셉니다. 반면 일부 공공기관 서류나 대학 과제는 공백 제외 기준을 명시하기도 하므로, 모집 요강이나 안내문에 기준 표기가 있는지 먼저 확인하는 습관이 필요합니다. 표기가 없다면 공백 포함 기준으로 준비하는 편이 안전합니다.

자기소개서 글자수 실전 팁

글자수 제한이 1,000자라면 제한의 90% 이상(900자 이상)은 채우는 것이 좋습니다. 지나치게 짧은 답변은 성의가 부족해 보일 수 있고, 반대로 제한을 초과하면 시스템에서 잘리거나 아예 제출이 막힙니다. 워드·한글 프로그램에서 작성한 뒤 채용 시스템에 붙여넣으면 줄바꿈·특수문자 처리 방식 차이로 글자수가 달라질 수 있으니, 제출 직전에 해당 시스템의 카운터로 최종 확인하세요. 이 도구로 초안 단계에서 분량을 관리하면 마감 직전에 문장을 급하게 잘라내는 일을 줄일 수 있습니다.

바이트 제한 시스템이라면

일부 오래된 채용·행정 시스템은 글자수가 아니라 바이트로 제한을 겁니다. 이때 널리 쓰인 관행이 한글·전각 문자 2byte, 영문·숫자·공백 1byte 계산법입니다. 예를 들어 "안녕hello"는 한글 2자(4byte) + 영문 5자(5byte) = 9byte입니다. 같은 글이라도 UTF-8 기준(한글 1자 = 3byte)으로 재면 훨씬 크게 나오므로, 제한이 바이트라면 시스템이 어떤 방식인지 확인이 필요합니다. 이 도구는 두 값을 병기하므로 어느 쪽 기준이든 바로 확인할 수 있습니다.

원고지 매수 환산

과제나 백일장에서 "원고지 10매 내외" 같은 분량 지시를 받았다면, 통상 공백 포함 200자 = 원고지 1매로 환산합니다. 공백 포함 2,000자면 약 10매 분량입니다. 실제 원고지에 옮기면 문단 들여쓰기와 줄바꿈 때문에 매수가 조금 늘어나는 경향이 있으므로 근사치로 참고하세요.

본 도구의 집계는 참고용 근사치입니다. 실제 제출 시스템의 글자수 계산 방식(줄바꿈 처리, 특수문자 처리 등)에 따라 수치가 다를 수 있으므로 최종 제출 전 해당 시스템에서 반드시 확인하세요.

자주 묻는 질문

자기소개서 글자수는 공백 포함인가요, 제외인가요?

대부분의 채용 시스템(잡코리아, 사람인, 각 기업 자체 채용 페이지 등)은 공백 포함 기준으로 글자수를 셉니다. 다만 일부 공공기관이나 대학 입학 서류는 공백 제외 기준을 쓰기도 하므로, 모집 요강에 별도 표기가 없다면 공백 포함으로 보고 준비하되 제출 전 해당 시스템에서 반드시 다시 확인하는 것이 안전합니다.

바이트(byte) 기준 제한은 어떻게 계산하나요?

과거 자기소개서 시스템에서 널리 쓰인 관행은 한글·전각 문자를 2바이트, 영문·숫자·공백을 1바이트로 세는 방식입니다. 반면 최신 웹 시스템은 UTF-8 인코딩 기준(한글 1자당 3바이트)을 쓰는 경우가 많습니다. 이 도구는 두 기준을 모두 표시하므로, 지원하는 시스템이 어느 기준인지 확인한 뒤 해당 값을 참고하면 됩니다.

입력한 글이 서버에 저장되나요?

아니요. 모든 집계는 브라우저 안의 자바스크립트로만 처리되며, 입력한 글은 서버로 전송되거나 저장되지 않습니다. 자기소개서처럼 민감한 글도 안심하고 붙여넣어 확인할 수 있습니다.

원고지 매수는 어떻게 환산하나요?

일반적으로 200자 원고지 1매는 공백 포함 200자로 환산합니다. 예를 들어 공백 포함 1,000자라면 원고지 약 5매 분량입니다. 실제 원고지에 옮겨 쓰면 문단 시작 들여쓰기와 줄바꿈 때문에 매수가 조금 더 늘어날 수 있으므로 근사치로 참고하세요.
